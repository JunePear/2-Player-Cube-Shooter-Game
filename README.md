# 2-Player-Cube-Shooter-Game
Welcome to 'THE CUBE GAMES'!!!

Here are the INSTRUCTIONS on how to play this 2 player game...
.Use WASD to move the red cube
.Use the ARROW KEYS to move the blue cube
.Click with your MOUSE to have the blue cube shoot

The following tells you the goal of each player:
- RED CUBE: The insentive of player 1(red cube) is to touch the blue cube while doging its bullets. If the bullet touches player 1, then it's speed will decrease by a random amount until it is decreased to 8, when which player 1 will lose.
- BLUE CUBE: The insentive of player 2(blue cube) is to kill the red cube with its bullets while avoiding being touched by the red cube. If the blue cube is touched by the red cube, then the blue cube will lose.

Here is how to download the game and actually play it: 
Download and Run the Installer

Go to the official website: python.org/downloads
Click the yellow button to download the latest version for Windows.
Open the downloaded .exe installer file
/If this doesnt work/:

Install Pygame Community EditionRun this command in your Command Prompt to install the compatible version: python -m pip install pygame-ce
Next, If it installs successfully, you can verify it by running: python -m pygame.examples.aliens

If the example game runs succesfully, then dowload the files and put them into a folder.
Run the .py file and enjoy the game!
